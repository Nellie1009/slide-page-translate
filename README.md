# Slide Page Translate

这个 skill 用于将课件逐页翻译成中文，并把原页与译页左右并排输出为 PDF。

## 文字版流程

```text
输入课件 PDF
    ↓
读取页数、尺寸和 PDF 原生文字
    ↓
逐页翻译原生文字并替换到译页，保留图形和原版布局
    ↓
Apple Vision 批量识别图片中的英文标签
    ↓
置信度 ≥ 0.5 → 结合本页语义修正 OCR → 翻译并覆盖原标签
置信度 < 0.5 → 30 分钟内不阻塞整批；若超时则只对漏项局部放大识别
    ↓
每页合成一张宽页：左侧原页 + 右侧中文译页
    ↓
自动检查页数、左右顺序、PDF 可读性，抽看少量代表页
    ↓
交付一个左右对照 PDF
```

原页保持不变。OCR 负责识别和定位图片文字，翻译由模型结合上下文完成；先使用 PDF 已有文字层，避免对同一段文字重复 OCR。中文较长时适度缩小字号或利用周围空白，不重绘图片和图表。
