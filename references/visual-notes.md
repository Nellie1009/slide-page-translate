# 逐页配图与简洁修订

适用：用户要求寻找中文教材/个人笔记图、把图贴在翻译侧、逐页讲清结构，或指出现有 PDF 配图冗余、难读。普通完整翻译无需自动启动全网找图。

## 1. 先对齐源页，再找素材

工作清单按“源文件＋实际页号”逐页记录：本页主题、独立知识点、图表标签/坐标/单位、需要说明的关系、拟用图及匹配理由、出处、核对状态。两份课件使用独立编号空间；合并顺序按用户要求，未指定则按输入顺序并说明。

“每个知识点都讲清”指逐页覆盖，不等于每页必须有一张新图。章节页、气胸等独立概念页、公式例题也要对应，不能用少数总览模块代替整份课件。源课件自己重复的图照原顺序保留；这是原页保真，不是允许右栏反复贴同一总览卡。

先查看原页高分辨率图。抽取/OCR缺失时放大相应区域再判断；缩略图上看不清的图注不能立即标为“原文无法辨认”。仍不清楚时注明具体位置，不猜病名、拍摄条件、数值或箭头方向。

## 2. 现成图的选择顺序

按本页具体对象和关系检索，例如“心室肌 动作电位 平台期 中文 标注”，而不是只搜“心脏 笔记”。可用中文教材、课程讲义、个人笔记或公开图谱；官方身份不是匹配度的替代品。专业事实存在冲突时，应另外查可靠教材或原始资料核对。

检查候选的完整原图与来源页，不仅看搜索缩略图：

- 对象、机制、阶段一致：心室肌、窦房结和神经元的动作电位不能混配；电传播图不能当作血流图。
- 关系与量纲一致：曲线横纵轴、单位、方向、图例、时间范围与本页相符；不靠“主题相近”代替逐项检查。
- 放进右栏后标签仍清楚。整页笔记若缩小难读，可在许可允许时截取相关区域，保留必要图例/坐标，并标明节选；不能截断条件造成另一种意思。
- 记录来源页 URL、作者/标题、许可或使用限制，交付中提供简短出处。个人笔记不是无版权素材；无转载依据时给出处并改用文字说明，不擅自搬整页教材、不去水印，也不把下载素材随 skill 发布。

用户说“优先找图”时，完成针对性检索与候选核对后再回退文字。用户说“不要自己画”时，不用自绘流程图、生成图片或重画解剖图来替代。没有匹配图就写清本页对应内容，并如实说明哪些页用了现成图，不声称每页都有中文笔记图。

## 3. 右栏的最小有效结构

完整翻译模式：本页标题 → 按原层级组织的完整译文/表格 → 确有增益的匹配图与短出处。图不是替代未译标签、漏掉条件或省略数据的理由。

用户明确选择讲解模式：本页标题 → 直接解释本页结构、曲线或公式的短说明 → 需要时放匹配图。通常一页围绕一个主要图解展开；复杂关系可合理拆分，但各部分要有明确用途。讲解可以简洁，仍需覆盖用户要求的每个知识点；不能把三句通用结论套到所有页面。

现成中文图直接占用翻译侧可读区域，配必要说明。避免把已含“原图＋译文”的旧双栏页再截图嵌进右栏，形成图中套图；不同时叠加内容相同的原图副本、总览卡、长标签清单和自绘流程。左侧已经保留的原页，不为了填满右侧空白再贴一遍。

“太复杂、越看越晕”的修订顺序：去掉重复图卡与无关图 → 合并重复解释 → 保留准确标签和关键关系 → 检查字号/留白。完整译文过长时允许续页，不靠缩成小字或删信息强压成一页。原稿留存，输出新版本。

## 4. 忠实翻译与纠错分开

原文译文保留原页说法；发现疑似错误时另外标“原文如此／待核实”或有依据的“译者注”，不能静默篡改，也不能把错误未经标记地重复给读者。外部笔记多出的机制、定义或限制注明“补充”，不假称来自课件。

典型核对：DPPC 的磷脂身份与课件“脂蛋白”旁注；压差与绝对压力；流量与流速；剪切力与剪切应力；每分钟通气量的单位；氧输送量与实际耗氧量。它们是检查提示，不是可直接套用到所有课件的答案。只在对应原页出现时查证、说明。

曲线页说明坐标、比较对象和读法；公式页解释符号、单位及适用条件；解剖页说明标注、方位与通路。不能把多种并列信号硬串成因果链，也不能从无色标的荧光图片编造定量变化。

## 5. 当前执行边界

`slide_translate.py` 的 `diagram` 是内置自绘结构图，不是图片插槽。当前没有 `image_path`、外部图片入栏、讲解模式或多文件合并参数；往响应中添加想象的字段不会实现这些功能。

- 完整翻译和无外部图的关系说明：继续使用现有 `prepare → validate → audit → build → verify`，保留全部条目与 ID。
- 必须嵌入现成图片或输出讲解版：先告知当前脚本限制。若当前任务授权开发支持，在现有脚本中做最小扩展并测试，保留原页映射、完整翻译模式的校验和真实复核状态；不要另写一次性生成器绕过这些保障。未具备能力时明确缺口，请用户选择文字版或后续扩展，不能擅自替换交付范围。
- 多份 PDF 合并：每个 job 先独立校验、导出，再使用可用的 PDF 合并工具，按清单核对源文件、页序、续页、书签。无额外页/续页时，输出页数应为各源文件页数之和；有续页则保留映射并说明。不要宣称脚本有不存在的 merge 子命令。
- 纯聊天模型只交接译文、配图选择和来源信息给执行端，不假称已下载图片、完成排版或生成文件。

本参考不降低完整翻译校验要求。若扩展讲解模式，应独立标明该模式与覆盖检查，不能通过删除原条目、虚报 reviewed 或改 status 让摘要冒充全译。

## 6. 验收与交付

先用少量代表页检查实际效果：结构/配图页、曲线/公式页、密集表格页。用户已有明确要求时自行验证后继续，不为每批额外要求确认。

最终检查全部输出页缩略图，并放大每张新加入的外部图、密集页、纠错页、续页及首尾页。核对：源页完整且对应正确；中文标签可读；图文不重叠；图文关系一致；字体、上下标、希腊字母、负号和单位正常。使用嵌入且覆盖所需字符的字体，不能只凭文本提取成功判断渲染无缺字。

最终只交付当前版本 PDF，简述完整翻译/讲解模式、源页与输出页数、实际配图范围及未解决限制。中间检索图、截图、JSON 和旧版不混作成品。
